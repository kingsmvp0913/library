還沒有金鑰？申請步驟（免費，不用綁信用卡）

  1. 到 建立專案，名稱隨便填，按「建立」。
  2. 到 Books API 頁面，確認左上角是剛建的專案，按「啟用」。
  3. 到 憑證頁面，按「建立憑證」→「API 金鑰」，複製那串 AIza 開頭的字。
  4. 貼到上面的欄位，按「測試看看」確認可用，再按「儲存」。

建議在憑證頁面把這把金鑰的「API 限制」設成只允許 Books API，這樣萬一外流也只能拿來查書。

先說清楚這個功能的極限

Google Books 對台灣出版的中文童書涵蓋率並不好，尤其是這兩年的新書， 常常查不到，就算查到也多半沒有封面圖。查不到時系統會直接展開手動填寫表單， ISBN 已經幫你帶入，你填書名並自己拍張照上傳當封面即可，不會卡住借還流程。

編號標籤印到哪裡

新增書冊之後印出來、貼在書背上的編號貼紙。預設用 A4，不必接任何設備。

印一張測試貼紙（上面一條細線、下面一塊黑），並自動複製診斷紀錄。 位置不對或印不出來時，把複製到的內容貼給維護系統的人。

選 B21 之前要知道的三件事

  • 要用 Chrome 或 Edge 開這個系統，其他瀏覽器沒有網頁藍牙功能。 每次重開瀏覽器後第一次列印，會跳出一個視窗要你選 B21，選過之後同一次使用都不會再問。
  • 買 50mm 寬的貼紙。B21 實際印得出來的只有 48mm，編號條碼本身就要 36mm， 50mm 的貼紙左右各留得下 6mm 空白，掃碼槍才好認。 40mm 的貼紙雖然印得下，左右只剩 2mm，掃起來會比較挑角度。
  • 熱感貼紙會褪色：B21 是靠加熱顯色、不用碳帶，貼紙受熱或日曬久了字會變淡。 編號是這本書永久的身分，若要撐好幾年，A4 雷射貼紙加一層透明膠帶反而更耐。
