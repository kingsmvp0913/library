# 幼稚園圖書／教具管理系統

單機使用，管圖書與教具：掃 ISBN 建檔、掃編號借還、還書時提示放回哪一格。

## 給使用者

- **第一次使用**：雙擊 **`安裝.bat`**
- **之後每次**：雙擊 **`啟動.bat`**（會自動更新到最新版）
- **關閉**：關掉黑色視窗

不需要懂 Node、PostgreSQL、git 或命令列。

## 資料維護的幾個規則

- **書櫃只有一層**，使用者只填名稱；代碼由系統自動產生（`S001`…）且不顯示。類型代碼同理（`C001`…）。
- **刪除一律先講原因**：書櫃還有幾本書、書目還有幾冊、這一冊有借閱紀錄——訊息要能照著做，不會出現資料庫的英文錯誤。
- **有借閱紀錄的東西不能刪**，因為刪了會讓歷史紀錄對不到人或書：
  - 書不見了 → 把那一冊的狀態改成「遺失」，不要刪
  - 小朋友畢業了 → 按「停用」，他會從借書下拉消失但紀錄留著
- **單冊的「借出中」狀態不能手動指定**，那是借還流程算出來的；能手動改的只有在架／遺失／修繕。
- **編號（barcode）永遠不能改**，它已經印出來貼在書上了。

## 設定（「設定」頁）

Google Books 金鑰在網頁上填就好，**不需要開設定檔**。頁面上有申請步驟、「測試看看」按鈕，
存好**立刻生效不用重開**（金鑰由 `lib/settings.js` 在需要時直接讀設定檔，不吃啟動時的 env）。
畫面只顯示遮蔽後的金鑰（`AIzaSy••••••xxxx`），API 不會回傳完整值。

`DATABASE_URL`／`PORT` 刻意不開放從網頁改——改錯會讓系統整個開不起來，那是維護者的事。

## 自動備份與系統紀錄（都在「匯入匯出」頁）

- **自動備份**：每次啟動系統自動留一份到 `data/backups/`，保留最近 30 份，使用者完全不必動手。
  資料庫還沒有任何館藏時不備份（免得空檔把有內容的舊備份擠掉）。備份失敗只印警告，**絕不擋住啟動**。
- **系統紀錄**：`data/logs/library-YYYY-MM-DD.log`，保留 14 天。只記啟動與錯誤，不記正常操作——
  每天幾百筆借還會把檔案灌爆，灌爆的檔案沒有人會看。
  使用者說「系統怪怪的」時，請他到匯入匯出頁下載當天的紀錄傳過來。

兩者的下載端點都只接受自己產生的檔名格式，擋掉 `../` 之類的路徑穿越。

## 借閱人與書櫃的明細

- **借閱人** → 點「明細」看他手上有哪些沒還、以及完整借閱紀錄（老師最常問「小明借了什麼還沒還」）
- **書櫃** → 點「明細」看這個櫃子上有哪些書、哪幾冊不在架上、在誰手上（盤點用）

全站搜尋搜到借閱人或書櫃時，點下去會直接展開對應的明細。

## 匯入匯出（「匯入匯出」頁）

- **匯出 CSV**：館藏／借閱人／借閱紀錄，Excel 可直接開（有加 UTF-8 BOM，中文不會亂碼）。
- **批量建檔**：先下載範本，填好再上傳。類型與櫃位要填系統裡已有的名稱。有問題的列會逐列列出行號與原因，其餘照樣建立。
- **完整備份**：JSON 格式，含借還紀錄與**編號流水號**（少了流水號，還原後發的新號會撞到已經貼在書上的條碼）。
- **還原**：會清空目前所有資料。系統會先自動下載一份還原前的現況當退路。還原時內部 id 會換一組，但**貼在書上的編號（barcode）原樣保留**。

## 給維護者

- **首次部署必須用 `git clone`**（不能解壓 zip），否則 `啟動.bat` 的自動更新不會生效。
- 設定都在 `data/config.json`：`DATABASE_URL`、`PORT`、`GOOGLE_BOOKS_API_KEY`。這個檔不進版控。
- 加了新的 npm 套件之後，要請使用者重跑一次 `安裝.bat`（啟動時不跑 `npm install`，太慢）。
- `安裝.bat` 存 CP950、`啟動.bat` 純 ASCII，兩者都必須是 CRLF。改完要**雙擊確認中文不是亂碼**。
- 開發規則見 `.claude/CLAUDE.md`，設計規格與實作計畫見 `docs/superpowers/`。

## 測試

```bash
npm run test:quiet          # 單元／API 測試（jest + pg-mem，不需啟動系統）
node scripts/e2e-smoke.js   # 端到端煙霧測試（需先啟動系統，打真的 PostgreSQL 與 HTTP）
```

兩者互補：jest 用 pg-mem，煙霧測試用真的資料庫 —— 兩者在 partial index 與 JOIN 上的行為並不相同，只跑其中一邊會漏。

前端沒有自動化測試，改動 `public/` 一律需要瀏覽器人工實測（含深色模式）。

## 目前已知的缺口

- **Google Books 需自備 API 金鑰**（免費）。未填時系統照常運作，只是中文書大多要人工填寫。填進 `data/config.json` 的 `GOOGLE_BOOKS_API_KEY` 即生效。
- **台灣 ISBN 全國新書資訊網（`server/lib/isbn/ncl.js`）尚未接通**。原假設的查詢網址回的是平臺框架頁，不含書目。此來源失敗只會回「查無」，不影響其他功能。
