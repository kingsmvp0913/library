# 前端規則

> 來源：改寫自 `C:\odoo-v2\.claude\rules\frontend.md`。**該專案用 Vue，本專案是原生 JS，Vue 專屬條目已刪除。**

1. **前端沒有自動化測試，改動一律需瀏覽器人工實測（含深色模式）。** jest 不涵蓋 DOM 互動；掃碼輸入、下拉自動完成、modal、配色只能人工點過。**不要宣稱前端改動「已驗證」，除非真的在瀏覽器開過。**
2. **禁止目測填 px、禁止寫死顏色。** 顏色與間距一律走 CSS 變數（`var(--danger)` 等）與共用 class。前端會不一致的根本原因是缺 design token，不是缺框架。
3. **寫死的淺色系顏色在深色模式會維持亮底**（白底黑字的卡片在深色模式變成刺眼白塊）。語意色一律用共用 class，不要 inline style。
4. **引用共用 helper 前先讀該檔核實函式名稱** —— 憑印象寫（例如以為有 `Api.del`，實際只有 `Api.delete`）會讓功能完全失效**而且不報錯**。
5. **全域元件（toast、confirm dialog）一律仿同一個模式**：全域函式 + 共用狀態 + 單一 host 節點。載入順序在頁面 script 之前。

## 本專案特有

6. **掃碼輸入框必須維持聚焦。** 掃碼槍是模擬鍵盤輸入的——失焦就掃不進去。點擊頁面其他地方後要能自動搶回焦點，且不能在使用者正在打字時搶走。
7. **借還畫面的「請放回：A櫃 · 第2層」必須是畫面上最大最醒目的元素。** 這是老師掃完書之後唯一要看的資訊，不能埋在小字裡。
8. **鏡頭掃碼是備援，不是主流程。** 相機初始化失敗（無權限、無裝置）必須靜默退回掃碼槍輸入，不可跳錯誤中斷作業。
9. **離線狀態要有常駐視覺指示**（右上角徽章），且必須說清楚影響範圍：「離線 · 自動補資料已停用」，而不是只顯示一個紅點。借還功能離線照常可用，不要讓使用者以為整套壞了。
10. **自動完成下拉要能純鍵盤操作**（方向鍵選、Enter 進、Esc 關）—— 掃碼槍會送 Enter，要確保 Enter 不會誤觸到非預期的項目。
